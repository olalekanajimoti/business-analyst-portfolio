## Recommended interview route

1. Start with **BOZ Jewelry** for retail, stakeholder and transformation evidence.
2. Use **NaijaFoodFestival** to demonstrate user segmentation and end-to-end service design.
3. Use **MyTicketSeller** for end-to-end product ownership: payments, currency rules, access control and live-defect root causes.
4. Use **Komfort Place Signature** for customer-journey redesign, conversion and analytics.
5. Use **Creatrix Empire** when the role requires data interpretation and performance reporting.
6. Use **Healthcare Facilities Request Handling** or **AI Evaluation** for judgement, quality and controlled environments.
